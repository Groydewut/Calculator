# CLI Calculator

Современный настольный калькулятор, разработанный на языке **Go** с использованием **Wails**. Приложение поддерживает выполнение базовых математических операций, автоматически сохраняет историю вычислений между запусками и предоставляет простой графический интерфейс.

# Принцип работы

После запуска создаётся экземпляр структуры Calculator.

Во время инициализации приложение пытается открыть файл `history.json`.

Если файл существует — история вычислений загружается.

Если файла нет — приложение начинает работу с пустой историей.

При каждом новом вычислении:

1. Выполняется математическая операция.
2. Формируется строка истории.
3. Запись добавляется в память.
4. История сериализуется в JSON.
5. JSON сохраняется на диск.

Благодаря этому после следующего запуска пользователь продолжает работу с уже существующей историей.

# Основные компоненты

## Calculator

Главная структура приложения.

Хранит историю всех вычислений.

```go
type Calculator struct {
    History []string
}
```

Отвечает за:

* вычисления;
* сохранение истории;
* загрузку истории;
* очистку истории.

---

## Calculate()

Главный метод программы.

В зависимости от выбранной операции выполняет соответствующее вычисление.

Поддерживаемые операции:

```
+
-
*
/
^
```

После успешного вычисления автоматически вызывает сохранение результата в историю.

---

## Record()

Добавляет строковое представление операции в историю.

Пример записи:

```
15 + 7 = 22
```

---

## Save()

Преобразует историю вычислений в JSON и сохраняет её в файл.

Используется сериализация через:

```
encoding/json
```

---

## Load()

При запуске приложения открывает файл истории.

Если файл отсутствует — ошибка не возникает, приложение продолжает работу.

---

## ClearHistory()

Полностью очищает историю вычислений и сразу сохраняет изменения на диск.

---

## GetHistory()

Возвращает историю вычислений для отображения в пользовательском интерфейсе.

---

# Обработка ошибок

В проекте реализована обработка наиболее распространённых ошибок.

## Деление на ноль

При попытке выполнить:

```
10 / 0
```

программа возвращает сообщение об ошибке вместо аварийного завершения.

---

## Отсутствие файла истории

Если `history.json` отсутствует, программа автоматически создаёт новую историю без завершения с ошибкой.

---

## Ошибки записи файла

При невозможности сохранить историю пользователю возвращается описание возникшей проблемы.

---

# Хранение данных

История вычислений хранится в формате JSON.

Пример:

```json
{
  "history": [
    "2 + 2 = 4",
    "15 / 3 = 5",
    "8 ^ 2 = 64"
  ]
}
```

Такой формат легко читать человеку и использовать в других программах.
